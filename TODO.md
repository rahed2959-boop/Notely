# Notely outcomes

- [x] **Local-first notes workspace**
  - Build an Android-focused mobile app for taking and tracking notes.
  - Persist notes, tags, and note states locally on the device.
  - Provide purposeful empty states and immediate onboarding-free interactions.

- [x] **Create and edit notes**
  - Let users create new notes and edit existing note content in a focused mobile editor.
  - Support a note title, body, and tags.
  - Save changes immediately back into the local notes list.

- [x] **Scannable notes list**
  - Display notes in a scannable list optimized for one-handed Android use.
  - Show useful metadata and keep pinned notes easy to identify.

- [x] **Search and organization**
  - Search notes by title, body, or tags.
  - Filter the list by tags or note status.
  - Create and assign tags to organize notes.

- [x] **Note state actions**
  - Pin and unpin important notes so they remain easy to access.
  - Archive and restore notes without deleting them.
  - Delete notes with a clear, safe interaction.

- [x] **Android-ready project delivery**
  - Configure the Expo starter project for Android-focused packaging and device-ready behavior.
  - Preserve the fixed Expo runtime and Android identifiers, and provide Notely launcher branding.
